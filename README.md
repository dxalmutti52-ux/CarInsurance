# CarInsurance Web Application

A simple ASP.NET Core MVC application for managing car insurance quotes.  
This project allows users to create, edit, view, and delete insurance records, with automatic quote calculation based on user inputs.

---

## 🚗 Features

- Create new insurance applications  
- Edit existing applications  
- View details of each insuree  
- Delete insuree records  
- Automatic quote calculation based on:
  - Age
  - Car year
  - Car make & model
  - Speeding tickets
  - DUI status
  - Coverage type (Full / Liability)

---

## 🛠 Technologies Used

- ASP.NET Core MVC  
- Entity Framework Core  
- SQL Server LocalDB  
- Bootstrap 5  
- C#  
- Razor Views
